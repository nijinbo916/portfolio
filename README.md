# 前端作品集

Web 开发技术课程第四次作业，用 HTML + CSS + JavaScript 做的个人作品集页面，
把前面做过的作品收集到一起，每个都有截图、在线地址和源码链接。

在线地址：

- Vercel：https://portfolio-theta-one-aig3koben9.vercel.app/
- GitHub Pages：https://nijinbo916.github.io/portfolio/

收录的作品：

- 用户注册页（第一次课作业）
- Quiz Game（第二次课课堂项目）
- 菜单搜索器（第二次课作业）
- Recipe Finder（额外做的接口版搜索器）

页面里的几个交互：

- 点截图可以放大看，按 Esc 或点旁边的空白处关掉
- 页面往下滚动时，内容会一个个淡入
- 滚到哪个区块，上面的导航就高亮哪一项
- 手机上自动变成一列

文件说明：

- `index.html` 页面结构
- `css/style.css` 样式
- `js/main.js` 交互
- `assets/shots/` 各个作品的截图

本地打开直接双击 `index.html` 就行。
